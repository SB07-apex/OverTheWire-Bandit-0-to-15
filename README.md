# OverTheWire Bandit — Levels 0–15

A clean documentation repository for **what the Bandit challenge itself asks us to do**, how to solve each challenge, and what concept each level teaches.

Bandit is an introductory Unix/Linux security wargame. OverTheWire describes it as a game for absolute beginners that teaches the basics needed for other wargames. citeturn0search0

## Structure

Each level contains:

- 🎯 **Challenge** — the task given by Bandit
- 🔎 **What we need to find**
- 💻 **Solution commands**
- 🧠 **Why the solution works**
- 📚 **Concept learned**
- 🔐 **Password / result**
- 📝 **Notes**

## Security note

Real Bandit passwords and private keys should not be published in a public repository. Use placeholders or keep credentials in a local ignored file.
